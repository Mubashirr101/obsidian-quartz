# Syntax

```sql

# sort in ascending order
SELECT * FROM person ORDER BY country_of_birth;

# sort in descending order
SELECT * FROM person ORDER BY country_of_birth DESC;
```

# Description

The ‘ORDER BY’ clause is used to sort the fetched table output as per any specified column.
By default it sorts in ascending order, to make it sort in descending order, use the ‘DESC’ keyword.
