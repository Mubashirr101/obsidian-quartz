# Keyboard Shortcuts

> [!info] Navigation
> Part of [[Excel]] · Windows shortcuts shown; Mac generally swaps `Ctrl`→`Cmd`, `Alt`→`Option`

## Navigation
| Shortcut | Action |
|---|---|
| `Ctrl+Arrow` | Jump to edge of data region |
| `Ctrl+Home` / `Ctrl+End` | Go to A1 / last used cell |
| `Ctrl+G` or `F5` | Go To dialog |
| `Ctrl+Page Up/Down` | Switch worksheet tabs |
| `Ctrl+F` / `Ctrl+H` | Find / Replace |
| `Alt+↓` | Dropdown list of unique values in column (quick autocomplete list) |

## Selection
| Shortcut | Action |
|---|---|
| `Ctrl+Shift+Arrow` | Extend selection to edge of data |
| `Ctrl+Space` | Select entire column |
| `Shift+Space` | Select entire row |
| `Ctrl+A` | Select all / current region |
| `Ctrl+Click` | Add non-contiguous selection |

## Editing
| Shortcut | Action |
|---|---|
| `F2` | Edit active cell |
| `F4` | Toggle absolute/relative reference (while editing formula); also repeats last action |
| `Ctrl+D` | Fill down from cell above |
| `Ctrl+R` | Fill right from cell to left |
| `Ctrl+;` | Insert today's date |
| `Ctrl+Shift+;` | Insert current time |
| `Alt+Enter` | Line break within a cell |
| `Ctrl+Enter` | Fill selected cells with same entry |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |

## Formatting
| Shortcut | Action |
|---|---|
| `Ctrl+1` | Format Cells dialog |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Bold / Italic / Underline |
| `Ctrl+Shift+$` | Currency format |
| `Ctrl+Shift+%` | Percentage format |
| `Ctrl+Shift+#` | Date format |
| `Ctrl+Shift+~` | General format |
| `Ctrl+Shift+&` | Add outline border |

## Rows, Columns, Sheets
| Shortcut | Action |
|---|---|
| `Ctrl++` | Insert row/column/cell |
| `Ctrl+-` | Delete row/column/cell |
| `Ctrl+9` / `Ctrl+0` | Hide row / Hide column |
| `Shift+F11` | Insert new worksheet |

## Formulas & Functions
| Shortcut | Action |
|---|---|
| `Alt+=` | AutoSum |
| `Ctrl+`` ` `` | Toggle formula view |
| `Ctrl+Shift+Enter` | Legacy array formula entry |
| `Shift+F3` | Insert Function dialog |
| `Ctrl+[` | Trace precedents (jump to referenced cells) |

## Tables & Filters
| Shortcut | Action |
|---|---|
| `Ctrl+T` | Convert range to Table |
| `Ctrl+Shift+L` | Toggle AutoFilter |
| `Alt+Down` | Open filter dropdown on active cell |
